#Tiendita Chida

##Descripción:
Tiendita Chida es una aplicación diseñada para la gestión y administración de una tienda, permitiendo organizar productos, controlar ventas y mejorar la experiencia del usuario mediante una interfaz sencilla e intuitiva.

##Características:
Gestión de productos
Registro de ventas
Administración de usuarios
Interfaz amigable
Base de datos integrada
Sistema de autenticación

##Tecnologías utilizadas:
Angular
Node.js

##Instalación:
*Clonar el repositorio
git clone https://github.com/usuario/tiendita-chida.git

*Entrar al proyecto
cd tiendita-chida

*Instalar dependencias
npm install

*Ejecutar el proyecto
npm start

##Uso
Inicia sesión en la aplicación.
Agrega productos al inventario.
Registra ventas y consulta información.
Administra usuarios y configuraciones.
Capturas de pantalla
